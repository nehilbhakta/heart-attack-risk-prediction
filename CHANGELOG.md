# Changelog

## [1.0.0] - 2026-11-12

First release. End-to-end ML pipeline (XGBoost on the UCI Cleveland dataset): risk-scoring API, simulated patient monitoring with alerts, and batch CSV/Excel upload (up to 500 rows — scored only, never stored). Demo/educational project with simulated data — not a medical device.

Live app: https://nehilbhakta-heartrisk.vercel.app
